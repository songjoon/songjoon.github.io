# songjoon.github.io

GitHub Pages에서 사용할 수 있는 CV(이력서) 예시 사이트 템플릿입니다.

## 사용 방법

1. `index.html`에서 이름, 소개, 경력, 학력, 기술 스택 정보를 본인 내용으로 수정합니다.
2. 저장소를 `main` 브랜치로 푸시하면 GitHub Pages에 반영됩니다.
3. 사이트 주소 예시: `https://<github-id>.github.io/`

## 수정 포인트

- 상단 프로필: 이름, 직무, 연락처
- 경력/학력: 기간과 성과 중심으로 간결하게 작성
- 기술 스택: 실제 사용 가능한 기술만 기재
- 프로젝트: 역할과 결과(수치 포함)를 함께 작성
